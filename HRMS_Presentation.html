User Roles & Access Control

Two distinct roles with different permissions and portals

👨‍💼

ADMIN Role

✅ Full employee management (Create/Edit/Delete)
✅ Approve/reject leave requests
✅ Approve/reject attendance submissions
✅ Generate, approve, process payroll
✅ Email payslips with PDF attachment
✅ View analytics and generate reports
✅ Manage master data (Dept, Banks, Holidays)
✅ View full audit trail log
✅ Manage user accounts
👤

EMPLOYEE Role (Self-Service)

✅ View and update own profile
✅ Submit monthly attendance for approval
✅ Apply for leave (AL, EL, MC, etc.)
✅ View leave balances and history
✅ View payslips (Approved/Processed)
✅ Download payslip PDF
✅ Email payslip to self
✅ Submit and manage timesheets
✅ Change password

🔄 Auto User Creation

When Admin creates an Employee → system automatically creates a User account (username = email prefix, default password = Employee@123) → Employee is forced to change password on first login

Authentication Flow

🔑

JWT Authentication

Secure token-based auth · 8-hour session · auto-refresh

🔄

Force Password Change

New employees must set own password on first login before accessing any screen

📧

Forgot Password

Reset link sent to registered email · 1-hour expiry token · secure BCrypt hashing

🛡️

Role-Based Routing

Admin → full system access · Employee → self-service portal only · Guards on all routes

🔒

Password Requirements

Minimum 8 characters · 1 uppercase letter · 1 number · BCrypt hashed in database
